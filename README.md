FindMate - 校园智能失物招领平台

FindMate 是一个面向高校校园的智能失物招领平台，旨在帮助学生更方便地发布失物信息、查找遗失物品，并通过智能匹配提高物品找回效率。

✨ 主要功能

 **失物发布**：发布丢失物品的信息，支持图片上传。
 **招领发布**：发布捡到的物品信息，帮助失主寻找物品。
 **物品搜索**：支持按名称、描述等关键词搜索物品。
 **智能匹配**：根据物品名称、描述、地点和时间等信息进行匹配，展示相似物品及匹配理由。
 **认领申请**：用户可以提交物品认领申请。
 **管理员审核**：管理员可以审核认领申请，管理物品状态。
 **数据持久化**：使用数据库保存物品和认领信息。

🛠️ 技术栈

前端：Vue 3
后端：Python、FastAPI
数据库：SQLite

🎯 项目目标

让校园失物招领更加便捷、高效，利用智能匹配技术减少信息查找成本，让每一件遗失物品都有机会找到主人。
